# kiwoom

## 로컬 화면 편집

편집용은 루트 `index.html`입니다. `demo/index.html`에는 편집 기능이 없습니다. `start-preview.cmd` 실행 후 `http://127.0.0.1:4178/index.html?v=v48`로 열면 오른쪽에 **화면 편집** 패널이 표시됩니다. 파일을 직접 열어도 동작하며, 변경사항은 해당 브라우저·주소에 임시 저장됩니다. 기존 다른 버전의 시안은 유지합니다.

- **시연**: 평소처럼 페이지를 이동합니다.
- **메뉴 이동**: Ver 4.8 메인의 9그리드를 끌어 순서를 바꿉니다. 대메뉴를 열면 그 안의 하위 메뉴도 정렬할 수 있습니다. 선택 후 `앞으로`/`뒤로` 또는 `Alt + 방향키`도 사용할 수 있습니다. 전체메뉴의 순서도 즉시 일치합니다. 하위 메뉴를 다른 대메뉴로 옮기는 기능은 포함하지 않습니다.
- **문구 수정**: 휴대폰 화면의 고정 문구를 더블클릭하고 적용합니다. 같은 메뉴 이름은 메인·전체메뉴·메뉴 검색에 함께 적용하고, 일반 문장은 현재 화면의 해당 위치에만 적용합니다. 실제 입력값, 이미지, HTML 구조, 업무 연결은 편집하지 않습니다. 다른 화면으로 이동할 때는 `시연`을 선택합니다.
- **변경사항 저장**: `kiwoom-content-edits.json`으로 저장합니다. 수정이 끝나면 이 파일과 함께 코드 반영 및 커밋·배포를 요청합니다. 저장한 파일 불러오기, 되돌리기/다시 적용도 지원합니다. 임시저장만으로 소스 코드나 배포본이 바뀌지는 않습니다.

코드 반영 명령: `npm run apply:content -- "편집파일의 전체 경로"`. 검증을 통과한 순서·문구만 `content-data.js`에 기록하며 `npm run test:demo`로 배포본을 다시 생성하고 확인합니다. 이후 요청한 시점에 커밋·배포합니다. 승인된 데이터만 공개 빌드에 포함하며, 로컬 편집 UI·임시저장·파일 내보내기는 빌드에서 제외합니다. 화면 구조나 원본 문구가 이후 개발 과정에서 달라지면 해당 일반 문구 변경은 자동으로 건너뛰므로, 반영 전 영향받는 화면을 확인합니다.

## 공유용 시연 페이지

`npm ci` 후 `npm run build:demo`를 실행하면 `demo/index.html`이 생성됩니다. 기존 루트 `index.html`은 변경하지 않습니다. 생성된 `demo` 폴더는 다른 위치에 복사해도 실행할 수 있으며, `index.html`을 더블클릭해 열거나 정적 서버에서 제공합니다.

공유용 페이지에는 Ver 4.8, Digital Form, 시연 기능만 있습니다. GitHub Pages는 `demo` 폴더만 게시하며 JavaScript/CSS는 압축하고 소스맵·테스트·개발 서버·원본 개별 소스 파일은 배포하지 않습니다. 배포 시 GitHub Actions가 매번 최신 소스로 다시 생성합니다.

`npm run test:demo`는 전용 페이지 생성, 원본 보존, 배포 파일 범위를 검사합니다.

모바일(화면 너비 700px 이하)에서는 오른쪽 아래 `+` 버튼 위로 버전 선택과 시연 기능 버튼이 바로 펼쳐집니다. `×` 또는 바깥 영역을 누르면 닫힙니다. 목록의 `숨기기`를 누르면 `+` 버튼도 사라져 고객 화면만 표시됩니다. 화면과 입력 상태는 유지되며, 새로고침하면 `+` 버튼이 다시 나타납니다. 데스크톱에서는 기존 왼쪽 패널을 사용합니다.

시연 기능은 인증 초기화, 본인인증 생략, 자동입력, 서류첨부, 퀵넘버플러스 고객 구분 순서입니다. 자동입력은 현재 ARS 인증 화면에 맞춰 휴대폰 정보·인증번호 또는 계좌 인증정보를 입력하며, 인증 완료 버튼은 직접 눌러 진행합니다.

퀵넘버플러스 미등록 고객은 계좌 인증 업무의 휴대폰 인증을 마친 뒤 별도 등록 안내 페이지를 봅니다. 기본 동의 체크박스 없이 `동의하고 등록하기` 또는 `지금은 건너뛰기`를 직접 선택합니다. 등록 선택 후 계좌 1개를 고르고 비밀번호를 확인해야 등록이 완료되며, 완료 시 현재 업무로 돌아갑니다. 건너뛰면 같은 접속 중에는 다시 권유하지 않고, 등록 완료 고객에게는 새 접속에서도 등록 안내를 보여주지 않습니다. 단순 증권계좌번호 조회는 기존대로 휴대폰 인증 후 목록만 보여주며, 이후 계좌 인증 업무에 진입할 때 등록을 안내합니다. 퀵넘버로 인증한 고객의 다른 계좌 이용은 휴대폰 인증 → 계좌 선택 순서입니다. 이 정적 시연은 등록 여부와 계좌 식별자만 브라우저에 보관하며 실제 전화번호 연결은 하지 않습니다.

모바일 시연 페이지는 키패드가 나타날 때 실제 표시 영역의 높이와 위치를 반영하고, 현재 입력란을 스크롤해 보여줍니다. 인증번호 요청·자동입력 후에도 입력란이 보이도록 유지합니다. 휴대폰 인증에서는 이름의 다음 키 → 생년월일 6자리 → 주민번호 뒷자리 첫 숫자 → 통신사 선택 → 약관 동의 순서로 이어집니다. 누락된 휴대폰 정보가 있으면 해당 입력란으로 돌아가며, 약관 동의와 인증 요청·완료는 사용자가 직접 실행합니다.

휴대폰 인증의 자동 이동은 PC 시연 화면에서도 동일하게 적용됩니다. 생년월일 입력 후 다음 칸의 기존 숫자는 선택되어 바로 바꿀 수 있습니다. 인증번호 요청 후 2초 뒤 시연 번호 `123456`이 자동입력됩니다. 사용자가 먼저 입력하면 자동입력은 중단됩니다. 다른 번호로 인증을 시도하거나 유효시간이 지나면 인증번호 아래 안내문을 오류·해결 문구로 대체하며, 수정 또는 재요청 후 안내문을 복구합니다. 실제 SMS 발송이나 서버 인증을 수행하는 기능은 아닙니다.

Ver 4.8 전체메뉴의 `메뉴명을 입력하세요.` 검색창은 현재 목록과 인기메뉴의 이름에 입력한 문자열이 포함된 항목만 검색합니다. 공백과 영문 대소문자는 구분하지 않으며, 설명·유사어·하위 화면의 메뉴명은 검색하지 않습니다. 결과는 중복 없이 모두 표시하고 대메뉴명과 일치 부분을 함께 보여줍니다. 입력 중 커서를 유지하며 검색 버튼/Enter는 키패드를 닫고 결과를 보여줍니다. 결과 선택 시 기존 메뉴와 동일한 인증·업무 경로로 이동합니다. 지우기/전체메뉴 보기는 원래 목록을 복구하며, 메인 검색어와 검색 기록에는 영향을 주지 않습니다.

로컬 미리보기는 `start-preview.cmd`를 더블클릭하거나 `node preview-server.cjs`로 시작합니다.
주소: http://127.0.0.1:4178/index.html?v=v48

서버가 실행 중이어야 오른쪽 브라우저 패널에 페이지가 표시됩니다. 앱이나 PC를 재시작한 뒤 연결이 거부되면 실행 파일을 다시 실행하고 페이지를 새로고침하세요. 이미 실행 중이면 서버를 중복으로 시작하지 않습니다.

## Ver 4.8 입력 컴포넌트 기준

앞으로 추가하는 입력란은 `v48-input-fields` 그룹 안의 `v48-input-field`를 사용합니다. 흰색 배경과 옅은 테두리의 둥근 입력란 안에서 왼쪽 항목명과 오른쪽 입력값을 한 줄에 배치하며, 기존 휴대폰 인증의 이름 입력란(`v48-phone-pill`)과 기본 스타일을 공유합니다. 항목명은 `label`과 `for`로 입력란에 연결합니다. 조회된 ID처럼 수정하지 않는 값은 `readonly`로 표시하고, 비밀번호는 `type="password"`로 입력합니다. 사용자 요청이 없는 기존 입력 화면과 이전 버전의 디자인은 유지합니다.

## Ver 4.8 결과카드 기준

앞으로 추가하는 결과카드는 ISA 가입서류 제출 조회결과와 고객정보 조회에서 공유하는 `iod-v45-card v48-result-card`를 사용합니다. 카드 안에 `toss-dhead`의 타이틀(`h2.td-title`)과 설명(`p.td-desc`), `v48-result-details`의 조회내용을 함께 배치합니다. 조회내용은 `v45-kv-row`의 왼쪽 항목명(`dt.v45-kv-k`)과 오른쪽 값(`dd.v45-kv-v`)으로 구성한 `dl`을 기본으로 하며, 14px 글자와 행 사이 구분선을 적용합니다. 카드 제목은 `aria-labelledby`로 연결합니다. 두 개의 하단 버튼은 카드 밖 `v48-auth-actions v48-result-actions` 안에 같은 너비로 배치하며, 주요 버튼에는 `v48-auth-button v48-lookup-action`, 보조 버튼에는 `v48-auth-button secondary`를 사용합니다.
