# Digital Form 업데이트 · 2026-10-28

- 바로가기: https://ejkim-kw.github.io/kiwoom/?v=dform
- 공개 버전 bb50a09를 기준으로 Digital Form 변경만 반영했다. Ver 4.8 소스와 화면 구성은 그대로 유지한다.
- 전문투자자 항목의 첨부구분은 소득요건 / 전문가요건 / 자산요건이다. 요건별 서류 안내와 공통 필수서류 안내를 제공한다.
- 공통서류 안내는 서류제출 목록과 같은 좌우 20px 여백을 사용한다.
- 필요서류 출처: https://www.kiwoom.com/h/banking/apply/VProInvestorBenefitView 및 연결된 개인전문투자자 이용가이드.
- 한 구분 이상 첨부 시 접수할 수 있는 시연이다. 서류 접수와 전문투자자 자격 등록은 별개이며 실제 파일 전송·심사 기능은 포함하지 않는다.
- 기존 v=dform 진입 기능을 재사용한다. 파라미터 없는 기본 접속은 기존 Ver 4.8로 유지한다.


## 전문투자자 세부요건 선택 · 후속 배포

- 전문투자자 분류 배지를 업무로 변경했다.
- 소득요건·전문가요건·자산요건의 물음표에서 안내를 펼치고 세부요건을 선택하면 필요서류별 첨부 화면으로 이동한다.
- 소득 2종, 전문자격 9종, 자산 구성 3종의 필요서류와 공통서류를 분리했다. 자산의 배우자 합산·담보대출은 추가 조건으로 함께 적용한다.
- 요건별 첨부는 별도로 보존한다. 다른 요건의 파일을 잘못 재사용하지 않으며 이전 요건을 다시 선택하면 첨부가 복원된다.
- 현재 선택에 필요한 서류를 모두 첨부해야 접수가 가능하다. 서류 제출 예외는 명시적으로 선택한 조건에만 적용하며 자격 심사·실제 파일 전송은 수행하지 않는 시연이다.
- Ver 4.8과 공용 실행 코드는 기존 공개 버전으로 유지했다. 바탕화면의 이전 원본과 디자인 참조용 demo 원본은 수정하지 않는다. 이 별도 배포용 복제본에서만 패키지를 생성한다.
