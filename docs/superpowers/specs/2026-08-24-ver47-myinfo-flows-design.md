# VER4.7 내정보 상세 흐름 설계

## 목표

VER4.7의 `내정보` 대메뉴 아래 다섯 중메뉴에 실제로 탐색 가능한 상세 흐름을 제공한다. 고령·저시력 사용자가 전화로 회귀하지 않도록 한 화면에서 한 가지 결정만 요구하고, 인증·선택·처리 결과를 명확하게 보여준다.

## 적용 범위

- VER4.7에만 적용한다.
- VER4.6 이하의 메뉴 라우팅과 기존 인증·자가해결 흐름은 변경하지 않는다.
- 샘플 고객·계좌·ID 데이터만 사용하는 인터랙티브 목업으로 구현한다.
- `계좌정보 조회 및 변경`은 조회 전용이며 화면 내 직접 수정 기능은 제공하지 않는다.

## 구조

`내정보` 중메뉴 라우터가 선택한 업무 키를 공통 내정보 흐름 엔진에 전달한다. 흐름 엔진은 업무 설정에 정의된 단계만 순서대로 렌더링한다.

공통 단계는 다음과 같다.

1. 휴대폰 인증
2. 계좌 또는 ID 선택
3. 계좌비밀번호 확인
4. 업무별 조회·입력 화면
5. 완료 화면

업무별 화면을 복제하지 않고 제목, 설명, 스텝, 목록, 완료 문구를 설정 데이터로 분리한다. 기존 VER4.7의 인증 입력, OTP, 계좌 카드, 상태 배지, 하단 고정 버튼 스타일을 재사용한다.

## 업무별 흐름

### 계좌정보 조회 및 변경

1. 계좌번호와 계좌비밀번호로 계좌 인증
2. 인증된 계좌 선택
3. 읽기 전용 계좌정보 표시
   - 주소
   - 연락처
   - 마케팅 수신매체
   - 직업
   - 거주국가
4. 하단 보조 행동 제공
   - `상담원 연결`
   - `영웅문S#에서 변경`

상담원 연결은 기존 상담 연결 안내를 사용하고, 영웅문S# 버튼은 기존 앱 연동 안내 팝업을 사용한다.

### 증권계좌번호 확인

1. 본인 명의 휴대폰 정보 입력 및 필수 약관 동의
2. 인증번호 입력
3. 보유 계좌 목록 표시

계좌는 상품 유형과 마스킹된 계좌번호를 카드 형태로 보여준다. 이 업무는 조회로 끝나며 추가 비밀번호 입력을 요구하지 않는다.

### 계좌비밀번호 재설정

1. 계좌비밀번호의 용도와 숫자 4~8자리 규칙 안내
2. 분실 시 직접 조회할 수 없고 재설정이 필요하다는 유의사항 표시
3. `영웅문S#에서 재설정` 버튼으로 기존 앱 연동 안내 팝업 호출

디지털 ARS 안에서 비밀번호를 직접 변경하지 않는다.

### ID조회 / PW재설정

1. 휴대폰 인증
2. 보유 ID 목록과 각 ID에 연결된 계좌 목록 표시
3. 대상 ID와 계좌 선택
4. 계좌비밀번호 입력 및 확인
5. 새 ID 비밀번호와 확인값 입력
6. `ID 비밀번호 재설정 완료` 화면 표시

새 ID 비밀번호는 기존 목업 규칙을 따라 영문과 숫자를 조합한 5~8자리로 안내한다.

### 장기미사용ID 제한해제

1. 휴대폰 인증
2. 장기미사용 제한 상태의 ID와 연결 계좌 목록 표시
3. 대상 ID와 계좌 선택
4. 계좌비밀번호 입력 및 확인
5. 제한해제 처리
6. `장기미사용ID 제한해제 완료` 화면 표시

## 상태와 검증

- 업무 키, 현재 단계, 선택한 ID, 선택한 계좌, 인증 상태를 VER4.7 내정보 전용 상태에 저장한다.
- 새 업무를 시작하면 이전 업무의 선택값과 입력값을 초기화한다.
- 필수 약관 미동의, 인증번호 미입력, 대상 미선택, 계좌비밀번호 4자리 미만, 새 비밀번호 불일치 상태에서는 다음 단계로 이동하지 않는다.
- 오류 메시지는 사용자의 잘못을 단정하지 않고 다음 행동을 구체적으로 안내한다.
- 완료 화면에서 `확인`을 누르면 VER4.7 홈으로 돌아간다.

## 접근성 및 화면 원칙

- 기존 VER4.7의 큰 글씨 배율과 고대비 색상을 그대로 지원한다.
- 모든 선택 카드와 버튼의 터치 영역을 44px 이상 유지한다.
- 선택 상태는 색뿐 아니라 체크 표시와 텍스트로 함께 표현한다.
- 단계 진행은 기존 3단계 세그먼트 헤더를 사용하고, 단계 수가 다른 업무는 설정값에 맞춰 표시한다.
- 긴 항목명은 한국어 단어 단위로 줄바꿈하며 컨테이너 밖으로 넘치지 않게 한다.

## 테스트

- VER4.7에서만 다섯 중메뉴가 상세 흐름으로 연결되는지 자동 테스트한다.
- 각 업무의 단계 구성, 샘플 데이터, 최종 행동 또는 완료 화면을 테스트한다.
- 필수 입력과 선택 누락 시 다음 단계로 진행하지 않는지 테스트한다.
- VER4.6에서는 기존 `이후 절차 정의 예정` 동작이 유지되는지 회귀 테스트한다.
- 브라우저에서 다섯 업무를 처음부터 끝까지 클릭하고 큰 글씨 모드에서도 카드·버튼·문구가 잘리지 않는지 확인한다.
